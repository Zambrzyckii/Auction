## Phase

**Backend complete for the main flow, no other module started.** On 2026-10-14 the pending-auction timeout and the funds-reservation saga for bids landed, followed the same day by the first gameplay batch: the starter item pack and player-to-player transfers. On 2026-10-15 the fifth module, Warehouses, landed with the warehouse wars from the third roadmap item, the sixth, Banking, with the turnover-gated loans from the fourth, and the seventh, Pawnshop, with the passive-income bots from the fifth. Before that the last code commit was `e684e33` from 2026-08-30. Register, login, create auction, bid, close and settle work end to end inside one process, with the known gaps listed below; the whole chain, both sagas included, was verified manually against the Compose stack on 2026-10-14, the warehouse war chain (stocking, entry locks, guarded raises, settlement with reveal and refunds) the same way on 2026-10-15, and the loan chain (turnover rejection, grant after a top-up, early repayment, keeper collection, overdue penalty with retry) the same day, with all six outboxes clean afterwards. The pawnshop chain was probed live against the Compose stack the same day with 33 checks, all passed. The probe covered the offers, the premises purchase with the turnover gate, the bot purchases and their conflicts, the spawns, the withdrawal, the automatic sale with its payout and the zero dead and zero stale pending rows across all seven outboxes. On 2026-10-17 the eighth module, Casino, landed with the chips, roulette and blackjack from the sixth roadmap item; its chain (free entry, the purchase saga with a rejection, a hedged roulette spin, the hidden hole card, the keeper's auto-stand of an abandoned hand, a cash-out that builds no turnover) was probed live against the Compose stack the same day with 34 checks, all passed, with zero dead and zero stale pending rows across all eight outboxes. On 2026-10-22 the ninth module, Profiles, landed with the user profiles from the seventh roadmap item (turnover-driven levels computed in Wallets, avatars in SeaweedFS, social links, friends, warehouse invites); its chain (profile creation from registration, level catch-up and rewards, social-link validation, the avatar round trip with the oversize and format rejections, the friend lifecycle with the auto-accepted cross request, the invites with their conflicts) was probed live against the fresh Compose stack the same day with 53 checks, all passed, with zero dead and zero stale pending rows across all eight outboxes and the level events visible in the Profiles inbox. On 2026-10-23 the platform work opened: phase one of the server-infrastructure plan landed (OpenTelemetry in the host, the Compose telemetry stack, the k6 scenarios with a baseline and thresholds), verified against the live stack and recorded in [performance.md](performance.md). Phase two followed the same day. nginx became the only entry point on port 8080, with IP rate limits, body caps, JSON errors and a JSON access log, the host trusts forwarded headers only from the pinned `edge` network, and health split into live and ready. The gateway was probed live against the restarted stack and measured in [performance.md](performance.md). On 2026-10-24 phase three put PgBouncer between the api and postgres, so the api, startup migrations included, reaches the database only through transaction pooling, probed live and measured before and after in [performance.md](performance.md). On 2026-11-01 phase four added the TTL read cache for the three Auctions reads (L1 in process, L2 on Redis, fail-open), and the seven-stage cleanup pass ordered after the 2026-10-24 architecture review finished the same day: the shared test stage with the first cross-module saga tests, the shared outbox with leased claims, the delivery split into transport and delivery (ADR-011) and the apply-once inbox (ADR-012), with the delivery hop measured in [performance.md](performance.md). On 2026-11-04 phase five put RabbitMQ behind the publisher seam (ADR-013): the Compose api publishes through the broker with publisher confirms, a host consumer feeds the same delivery store, the four public auction events go out on the consume-only market exchange for the bots, and a registration probe verified the chain end to end with clean tables. Phase six followed the same day (ADR-014): the api reads its five secrets from OpenBao through a hand-written configuration provider behind a fail-fast `Vault` section that defaults to off, the infrastructure containers moved to generated file secrets, every plaintext secret left `compose.yaml` and the legacy `Backend/.env` files are gone, with the chain and the manual-unseal drill of the persistent mode verified live and written down in [operations.md](operations.md).

## What exists

- `Backend/`: the host `AuctionServer.Api`, the modules Identity, Wallets, Auctions, Inventory, Warehouses, Banking, Pawnshop, Casino and Profiles (consume-only, no outbox) the contracts project `Shared.Integration` and the shared outbox, inbox and delivery implementation `Shared.Infrastructure`; 51 endpoints, 38 integration events, 39 tables, eight `OutboxProcessor<TContext>` instances, one `DeliveryProcessor`, `AuctionCloser`, `WarehouseKeeper`, `BankKeeper`, `PawnshopKeeper` and `CasinoKeeper`.
- Tests: eleven xUnit projects (one per module, the host project `AuctionServer.Api.Tests` and `AuctionServer.Shared.Infrastructure.Tests`), 910 test methods, with the saga tests in `Api.Tests` the only ones crossing a module boundary.
- CI: `.gitlab-ci.yml` and its GitHub Actions mirror `.github/workflows/ci.yml`, both with `build`, `unit-tests`, `integration-tests` and `gateway-config` (`nginx -t` on the gateway configuration).
- Documentation: `docs/en` and `docs/pl` with this set of pages and 19 rendered diagrams; root `README.md` and `README.pl.md`.
- `Backend/Dockerfile` and a root `compose.yaml` (the nginx gateway in front of the API + PostgreSQL behind PgBouncer + Redis for the read cache + RabbitMQ as the event transport + SeaweedFS for avatars + OpenBao with its one-shot `vault-init` seeder for the secrets, plus the telemetry stack of OTel Collector, Prometheus, Tempo and Grafana, split into `edge` and `data` networks with frozen resource limits, migrations applied at startup behind `Database:MigrateOnStartup`); k6 load scenarios behind the `loadtest` profile, configuration under `Infrastructure/`, secret files generated once by `Infrastructure/secrets/gen-secrets.sh`. `compose.debug.yaml` additionally publishes the API on `127.0.0.1:8081` and the vault on `127.0.0.1:8200`, and `compose.vault-persistent.yaml` switches the vault to raft storage with a manual unseal.
- CORS for the configured frontend origins (`Cors:AllowedOrigins`), the OpenAPI document at `/openapi/v1.json` (private networks only through the gateway) and `/health`, `/health/live` and `/health/ready`.
- Not in the repository: frontend, bots.

## Development environment

- .NET SDK 10.0.301 and `dotnet-ef` 10.0.9; every project targets `net10.0`.
- Docker for the local PostgreSQL and for Testcontainers (`postgres:16-alpine` both in tests, through the shared `TestDatabase.Image` constant, and in `compose.yaml`); after a one-time `./Infrastructure/secrets/gen-secrets.sh`, `docker compose up -d` starts the whole system behind the gateway on `http://localhost:8080`, with Grafana on `http://127.0.0.1:3000` and the RabbitMQ UI on `http://127.0.0.1:15672`.
- Node.js 26 and Python 3 only for re-rendering diagrams (`docs/diagrams/render.py`).
- IDE: Rider (`Backend/.idea/` is ignored, `AuctionServer.sln.DotSettings.user` is tracked).

## Known gaps

- Nothing blocks a browser client any more; the remaining smaller limitations are listed in [ARCHITECTURE.md](ARCHITECTURE.md#known-limitations).
- The gateway has no TLS yet, so the stack must not face the internet, see [infrastructure.md](infrastructure.md#what-is-missing).

## Next step

The first batch (starter item pack, player-to-player transfers) shipped the same day, the warehouse wars, the bank and the pawnshop followed on 2026-10-15, the casino on 2026-10-17 and the user profiles, the last gameplay item, on 2026-10-22, with the private-profile option following the same day. The Redis read cache (2026-11-01), then RabbitMQ and OpenBao (both 2026-11-04) followed. The next step of the server-infrastructure plan is the seventh and last phase, hardening, with the Angular frontend and the AI bots after that ([VISION.md](VISION.md)).
